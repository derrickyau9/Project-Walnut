# Project Walnut naming

**They made the leaf. We cracked the nut.**

Project Walnut is the camera ecosystem and engineering project. Walnut FF-1
is its planned first full-frame camera body; the name does not indicate that
the physical camera is complete. DaOS Camera remains the camera software
platform.

Project Walnut 是整个相机生态与工程计划的名称；Walnut FF-1 是计划中的首款
全画幅机身，并不表示整机已经完成。相机软件平台继续使用 DaOS Camera 名称。

| Name | Meaning |
| --- | --- |
| Project Walnut | The project, community and camera ecosystem. |
| Walnut FF-1 | The planned first camera body; existing engineering gates still apply. |
| DaOS Camera | The camera software platform. |
| HUMI | Hardware Universal Mount Interface, the interchangeable mount interface research. |
| HF-Sim | The existing synthetic image-source identifier; it does not represent a physical sensor. |

## Stable technical identifiers and historical records

HUMI keeps its interface identifier, with **Hardware Universal Mount Interface**
as its current full name. “Universal” describes the research goal, not verified
lens compatibility. Its requirements and test boundaries remain in the
[mount interface plan](../../mounts/README.md).

The rename changes presentation names. Existing `HF_*` and `hf-*` identifiers,
API/schema names, `/opt/hasslefree` paths, package names and stored filenames
remain stable so that existing tools and data keep their meaning.

The [verbatim original requirements](original-user-specification.md), imported
hardware sources, licenses and recorded build/test evidence retain their
original names and bytes. They are historical records rather than the current
project identity. Naming does not alter their provenance, publication rights
or acceptance status.
