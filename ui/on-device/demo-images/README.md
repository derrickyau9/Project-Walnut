# Project Walnut demonstration photographs

These three JPEG files were explicitly provided in the project conversation for viewfinder and photo-workflow demonstrations. The original JPEG bytes are retained. The supplied copies contain no EXIF fields, including GPS or camera identity metadata.

These are sample photographs, not photographs produced by the prototype sensor or by HF-Sim. Demo mode must identify the sample preview; the synthetic capture authority keeps its own RAW output and provenance.

这三张照片由项目对话明确提供，用于取景、回放、比较和非破坏编辑演示。它们不是原型传感器或 HF-Sim 拍摄的照片。示例预览与合成 RAW 采集来源应分别标示。
