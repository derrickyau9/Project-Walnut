# HassleFree FF-1 · v0.3 条件式非接触导热桥

2026-11-05。v0.1 / v0.2 保持原样；本包是另存的工程概念版本。

**这版没有解决或宣称解决传感器散热。** 它把一个可调导热接口布置到传感器旁边，在空间上跨越原来的 19 mm 轴向距离，但不连接、接触或压住未知传感器，也不使用传感器载架作反力面。热源接口仍断开，温升、导热能力和可靠性均未验证。

- `exports/HassleFree_FF1_concept.blend`：可修改场景，包含可切换的非物理避让区显示。
- `exports/HassleFree_FF1_E_preview.glb`：按米制缩放的普通浏览模型。

## 实际设计了什么

1. **一体式固定导热基体候选。** 原后方集热板扩展出侧臂、安装横梁和固定导轨，三者合成一个连通实体，不再把未固定的贴合面冒充牢固连接。拟通过机架上的两个匹配孔独立安装；具体螺钉/螺母、绝缘、防松和预紧仍待选定。铜色仅为导热材料候选的显示，不是确定的材料牌号或性能。
2. **单侧滑动接口。** 位于机身坐标 X=+42 mm 附近，利用相对于传感器载架的外侧空间，避开储存路径。滑片沿光轴方向滑动，端部是一个孤立的侧向接合面。它不伸进传感器中心，也不靠传感器定位。
3. **槽与夹紧件空间。** 槽宽名义 2.7 mm，总长 6.5 mm；轴杆占位直径 2.5 mm，形成名义 4 mm 极限行程。螺钉/螺母文件只是空间预留，**没有真实螺纹，不能照这些零件加工、打印或声称已有可靠夹紧力**。
4. **明确不连接热源。** 固定基体和滑片只有名义接触面。实际接触压力、表面处理、氧化层、TIM、接触热阻以及热量最终如何散出机身均未知。

## 调整范围与基准

光轴朝镜头为 +Z，传感器名义有效面为 Z=0；固定集热面在 Z=−21。

- 标称接合面 Z=−2，对应轴向跨度 19 mm。
- 名义槽端硬边界 Z=−5 / −1，对应 16 / 20 mm。
- 两端轴杆与槽端为名义接触，**不是公差合格的可用端点**。
- 默认配置只允许 Z=−4.5 至 −1.5 的候选设置区间，即轴向跨度 16.5–19.5 mm，给名义槽端各留 0.5 mm。该余量仍不是经制造公差验证的保证。
- 选好真实夹紧件、制造工艺和公差后，必须重新定义有效行程与限位。

前方接合面始终在 Z=0 后方，但这并不能证明它避开未知实际封装；真正的封装、PCB、FPC 和热接口仍须补齐。

## 公共芯片尺寸与未知封装必须分开

Sony 官方 IMX410CQK flyer 给出：

- Chip size：41.071×30.815 mm。
- Package：294-pin LGA。
- **没有给出本设计需要的完整封装外形、厚度、感光面高度、机械公差和热安装接口。**

本版仅把 41.071×30.815 mm 作为平面最低限度，再加每边 2 mm 的人为路由余量，得到 45.071×34.815 mm 的排除区。其轴向范围 Z=−21…0 来自现有设计空间，绝不是公开的芯片/封装厚度。实际封装可能更大、更深，或需要额外 PCB/FPC 空间。

旧模型的 40×28 mm 传感器占位仍仅用于对照，已经小于这组公开 chip size。**本版没有把旧载架改成或宣称它是 IMX410 安装结构。** 光敏面、安装堆叠和热接触面不能凭公开 chip size 猜测。

## 已验证到哪里

- 所有新实体有效；固定导热基体为单个连通实体。
- 两种法兰参考装配分别检查 435 对零件组，名义实体无正体积重叠。
- 调整位置 Z=−5、−4、−3、−2、−1 五档检查：无已建模零件重叠，避开排除区，不接触旧传感器占位、载架、支点或桥架。
- 标称导轨到载架最小间隔约 7.7 mm，到传感器桥架约 6.7 mm；这些只描述当前模型，不能代表真实封装间隙。
- 在两个名义槽端再尝试 0.2 mm 超行程，会与保留的轴杆占位发生干涉，验证了几何止挡意图；并不证明真实限位、锁紧或寿命。
- 电池、储存、控制板、传感器桥架的原维修检查继续保留。
- 新导热总成可在先拆后盖/屏幕/控件、主板/控制电子和横梁，并释放其固定件后整体向后抽出；当前传感器组件可以保留。使用固定基体构造子件的连续保守包络扫掠，并验证子件重新合并等于原实体。
- 先拆完整导热总成后，传感器桥架的后抽路径仍成立。

所有拆装检查都没有包含尚未选定的真实紧固件、线束、连接器配对、绝缘与密封件。报告明确保留 `engineering_release_ready=false`。

## 为什么仍不能称为“不影响传感器”或“散热完成”

目前能确认的是**没有直接几何接触，也没有把传感器或载架设计成夹紧反力面**。导热基体拟与机架相连，共用机架仍可能产生热膨胀、机械变形或间接改变光学基准，这些未做热-结构耦合验证。

仅仅把金属件伸到附近不能把传感器的热带走。必须取得供应商明确允许的热接口，然后决定是否采用被批准的壳体/模组接口或柔顺连接。不得凭本模型把硬块、弹簧或导热垫压在裸芯片、盖玻璃或未经批准的封装表面。

## 下一阶段的 P0 输入

1. 选定传感器/模组的正式机械图、光敏面高度、安装/夹持禁区和允许热接口。
2. 主控与传感器功耗、工作周期、温度限值及环境工况。
3. 完整 populated PCB、配对连接器和线束体积。
4. 机架及导热基体材料/制造方法、紧固件、接地/绝缘与装配公差。
5. 实际镜头接口与后组包络。E/EF 文件仍只是 Z=18/44 的名义法兰参考，不是兼容卡口。

拿到这些之前，不做温升/散热瓦数承诺，不冻结传感器安装，不发布加工图。

## 参数与复现

`source/parameters.json` 中 `thermal_bridge.front_z` 是当前设置；固定集热面、XY 路由、导轨、槽和排除区也有显式参数。主模型会拒绝缩小关键排除区、低于已验证 chip XY、禁用却仍生成、槽/轴不一致以及超出候选可用区间的设置。它不是能自动保证任意参数组合安全的设计器，**每次修改都必须跑全部审查**。

```sh
python source/build_camera.py
python source/audit_feasibility.py
python source/audit_thermal.py
python source/audit_parameters.py
python source/draw_datums.py
blender -b -t 6 --python source/render_camera.py -- --renders 04,05,07,08
python source/final_qa.py
```

完整场景也可不带 `--renders` 重渲染。源模型需要 CadQuery 2.7，场景脚本使用 Blender 4.3。
