## 这版做了什么

1. **独立壳体与骨架。** 深石墨机身、突出右手握柄、单独握柄包覆件、前壳与后盖。金属骨架承担镜头接口载荷，外壳不作为传感器定位基准。
2. **独立传感器支撑。** 36×24 mm 有效感光面，载架通过三个独立支点连接到内骨架。三点支撑仅表示可调/校准架构；没有虚构垫片精度、实际传感器封装、IBIS 或已验证的热补偿结构。
3. **HUMI 可换卡口。** 内骨架的共同接口位于 Z=12。短模块名义镜头法兰位于 Z=18，长模块位于 Z=44，所以模块轴向长度相差 26 mm。当前方案为维修式螺钉固定概念，不是已经实现的免工具快速更换机构。
4. **基本操作与维护。** 后屏、顶部快门与拨盘、后部按钮、底部抽取电池、左侧抽取储存模块。卡仓/电池门有独立几何件，但没有完成铰链、锁扣、防水胶圈或线束设计。
5. **低速控制板占位联动。** 使用 PCB 团队 A0 板的实际平面外形与孔位，名义占位 60×42×1.6 mm；四个 Ø2.7 mm 非金属化安装孔。两颗台架按键不是量产相机的双行程快门。J1 直立排针朝镜头方向；主处理板的占位体为它预留了缺口。线束、插拔行程、连接器具体配对及螺柱都尚未定版。

## 坐标与尺寸假设

- X：从机身正面看向右；Y：向上；Z：沿光轴朝镜头。默认右手版的握柄位于负 X，背面操作时在使用者右手侧。
- 传感器有效面：Z=0，36×24 mm。传感器封装是未选型占位。
- 主体外形：112×96 mm 正面轮廓，右侧加入 41 mm 宽握柄并与主体重叠。主体后面 Z=-45，前面 Z=12。圆角、壁厚、握柄尺寸和开口均为可更改假设。
- 包含门、按钮和握柄包覆的装配包络约 **150.7×100.0×65.0 mm（E 概念）**，EF 概念深约 **91.0 mm**。不含镜头、背带或外接线，精确模型包络记录在 `validation/geometry_report.json`。
- 壳体壁厚目标约 2 mm，局部握柄和连接区域不均匀；还没有制造工艺、拔模角或翘曲验证。
- HUMI 共同接口外径 74 mm；概念孔圈 64 mm、六个 Ø3.2 mm 孔。它们是自定义占位，不是既有标准，也不是制造公差。
- 卡口模型通孔 50 mm 是包装假设，**不能据此判断任意镜头的全画幅覆盖、后组避让或实际兼容性**。
- E/EF 两个平滑环只表达名义法兰平面与空间。没有提供或复刻专有卡爪轮廓，没有锁销、解锁机构、弹片、镜头电触点或电子协议。文件名中的 E/EF 不表示可安装真实镜头。
- 未选定的电池包占位 29×61×22 mm；不代表特定电池、能量、保护电路或安全认证。
- 未选定显示模块占位 72×49×3 mm。屏幕文字只是界面示意。

## 控制板坐标

PCB 原点左上，X 向右、Y 向下。孔中心是 (3,3)、(57,3)、(3,39)、(57,39)。转换到机身坐标为：

默认右手版：`X_camera = 38 - X_board`，`Y_camera = Y_board - 21`。真实 PCB 在板面内旋转 180°，没有镜像铜层或元件面。

板背面放在 Z=-37，元件面以名义板厚 1.6 mm 放在 Z=-35.4。连接器朝 +Z。附带的原始 KiCad board-only STEP 的实体范围是 X 0…60、Y -42…0、Z 0…1.51；**该 1.51 mm 板体实体不等于确认后的成品板厚**。机械装配按名义 1.6 mm 预留，板厂叠层未冻结。

## 可编辑源文件

`source/build_camera.py` 是参数化 CadQuery 主模型；`source/parameters.json` 集中保存有效面、法兰平面、主要包络和板位置，其余局部几何可直接修改 Python 源码。没有要求使用付费 CAD。源码的初始布局坐标把握柄放在正 X；默认 `right_hand_grip=true` 会在加入装配时镜像机械件、对控制板做平面内旋转。实际交付 CAD 坐标以导出结果为准。

在已安装 CadQuery 2.7 的 Python 环境中运行：

```sh
python source/build_camera.py
```

会重新生成各零件 STEP/STL、两种装配 STEP、清单和几何报告。如果改了法兰位置、包络或 PCB 输入，应重新运行并检查，不要直接沿用旧渲染。

在 Blender 4.3 中重新生成效果图：

```sh
blender -b -t 6 --python source/render_camera.py
```

Blender 里的轻微倒角仅为显示高光，不等于源 CAD 已增加制造倒角。STL 没有可靠单位元数据，不应直接用于精密加工。GLB 的物理尺寸可在导入软件中核对。

## 已做的验证

- 所有零件组的 OpenCascade B-rep 有效性检查。
- 13 对关键包装体的实体相交检查：电池/壳体、电池/骨架、传感器载架/骨架、感光面/载架、显示/后盖、主板/骨架、控制板/骨架、控制板元件/主板、控制板元件/散热板、储存/骨架、前壳/骨架、两种卡口/前壳。
- 4 项名义参数检查：36×24 有效面、18 mm 与 44 mm 法兰距、两种法兰位置相差 26 mm。
- STEP 回读和最终图像人工视觉检查另见 `validation`。模型正确导出不等于机械方案可制造。

## 尚未完成，不能据此宣称通过

全装配公差链；所有零件的全配对干涉与装拆路径；镜头实际后组包络及通光锥；传感器盖玻璃/滤镜/除尘堆叠；机械快门空间；主处理板、电源、接口与线束；散热、结构强度、跌落、振动、EMI、防水；真实镜头卡口配合与锁止；电池保护和认证；人机尺寸实测；完整螺钉、螺柱、接地与工艺。
