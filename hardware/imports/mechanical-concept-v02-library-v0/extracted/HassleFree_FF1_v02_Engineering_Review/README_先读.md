# HassleFree FF-1 · 机械工程审查版 v0.2

2026-11-05。单位：毫米。v0.1 原交付完整保留，v0.2 是新文件，不覆盖旧交付。此版本修正已测出的几何问题并补上拆装验证，仍然是待选型、待公差设计的机械方案，**不是可制造、可安装真实 E/EF 镜头或可工作的相机认证**。

源码初始布局把握柄放在正 X；默认 `right_hand_grip=true` 在输出时镜像机械件、对真实 PCB 做平面内旋转。真实 PCB 未镜像，实际坐标以导出 CAD 为准。

在 CadQuery 2.7 / Python 环境运行：

```sh
python source/build_camera.py
python source/audit_feasibility.py
python source/draw_datums.py
blender -b -t 6 --python source/render_camera.py
```

Blender 的轻微边缘高光不代表源 CAD 有制造倒角。修改尺寸或输入板后，必须重新生成并检查，不能沿用旧图片或报告。

## v0.1 审查发现与 v0.2 修复

这些数值来自导出 STEP 的实体相交计算，不是凭渲染观察推测。

1. **前后壳相交 322.090 mm³、握柄包覆相交 57.283 mm³。** 已分离实体；当前为名义贴合面，未替代制造间隙、公差和连接设计。
2. **顶部快门相交 78.540 mm³、后按钮相交 45.848 mm³。** 加入轴杆和通孔，帽体与壳体保持名义间隙。仍未验证开关行程、回弹、保持或电子连接。
3. **电池在静态可放入，但向下抽出 3–4 mm 会碰壳。** 修整圆角内腔与底部开口的过渡，增加连续抽取通道。概念空间余量为每侧 0.5 mm，不是已确认的配合公差。
4. **传感器占位件只搭在四个小角上。** 40×28 mm 占位件原来对着同尺寸带圆角孔，总支承面积仅 0.858 mm²。孔改为 38×26，形成名义 1 mm 连续托边，支承面积 132.858 mm²。该修复只对假设占位件成立，不代表适配任何真实传感器。
5. **原传感器横梁与骨架一体，直线维修路径不明确。** 新增独立后抽式传感器桥架 27，保留三点载架，四角固定位置与骨架接触。实际螺钉、螺纹、锁紧、定位与校准仍未冻结。
6. **控制板没有安装支撑。** 新增可拆横梁 28 和四个支柱 29，与真实板上的 Ø2.7 安装孔对齐。尚未选择实际紧固件、绝缘和接地方法。
7. **卡口基准筒孔外壁仅 0.4 mm。** 概念外径由 68 改为 72 mm，基准法兰外径改为 74 mm，孔外壁名义剩余 2.4 mm。它只是几何加厚，未证明扭矩、疲劳或螺钉座合格。
8. **前面的十字不能准确表示传感器平面。** 已改成机身侧面 Z=0 的名义焦平面符号。符号不是校准后的测量基准面。

## 坐标与名义尺寸

- X：正面看向右；Y：向上；Z：朝镜头。右手握柄位于负 X，背面操作时在使用者右侧。
- 有效感光面 36×24，前面 Z=0。
- HUMI 概念公共界面 Z=12；短/长基准法兰 Z=18 / Z=44，差 26。
- E/EF 名称只指这些公开的名义轴向参考。模型没有真实卡爪、镜头锁止、电触点、弹片、释放机构或电子协议。
- 镜头模块概念通孔 50 mm、HUMI 孔圈 64 mm、六个 Ø3.2 mm 孔，都是待核对的自定义假设。不能从这些尺寸推断真实镜头覆盖或后组避让。
- 含外壳、门、握柄包覆与控件的包络约 **150.7×100.4×65.0 mm**；长法兰版本深约 **91.0 mm**。不含镜头、背带、配线；精确包络见 `validation/geometry_report.json`。
- 电池占位 29×61×22，显示占位 72×49×3；未选具体产品，不能据此推断容量、能量、续航或认证。
- 主处理板、热方案、电池、储存、显示和传感器封装仍是占位体。所有壳厚、桥架、支柱、孔位余量均未经过制造工艺和公差设计。

## 真实控制板与占位的边界

使用最终 A0 board-only STEP 的实际平面轮廓和孔位，按名义 1.6 mm 板厚重新拉伸。原始 KiCad STEP 的板体是 1.51 mm，不等于已确认的成品叠层。它作为原输入保留在 `source/FF1_Control_A0_board_only.step`。

PCB 自身坐标从左上起，X 向右、Y 向下；转换为机身坐标：

`X_camera = 38 - X_board`，`Y_camera = Y_board - 21`。

安装孔中心在机身坐标 X={−19,35}、Y={−18,18}，直径 2.7。板背面 Z=−37，元件面按名义厚度在 Z=−35.4；支柱前端 Z=−33.4，横梁前面 Z=−31.4。

只建了两颗台架开关与 J1 直立排针的简化包络，**这不是完整装配 PCB 的碰撞验证**。两颗开关不是双行程相机快门。J1 朝 +Z，主处理板占位为其预留缺口；真实配对连接器、线束和插拔空间未验证。外部按钮和拨盘未接到该板。

## 几何验证与有条件的拆装顺序

- 29 组零件的 B-rep 有效性与两套 STEP 回读。
- E / EF 两套装配分别检查 **351 对**不同零件组。结果为零正体积相交；这是名义实体检查，不是公差、装配力或完整零部件检查。
- 保留 v0.1 的 13 对选定检查和 4 项光学尺寸检查，另有新增的全配对报告。
- **电池：**先卸底盖，沿 −Y 抽出 110 mm。用覆盖真实零件的连续包络扫掠做保守检查。
- **储存：**先卸侧盖，沿 +X 抽出 80 mm，同样做连续保守扫掠。
- **控制板与横梁：**先卸后盖、屏幕和控制帽，断开线缆并释放紧固件，再整组沿 −Z 抽出。对当前等截面实体做连续精确扫掠，重建截面与原实体的对称差也经过检查。
- **传感器桥架：**上述零件卸除后，再卸主板和热方案占位体、相关配线及紧固件，整组沿 −Z 抽出 110 mm。连续扫掠检查涵盖全部保留的已建模零件，而不只是骨架。

这些顺序没有验证未建模紧固件的工具可达性、线缆拆接、粘接、密封或真实器件。报告中的 `geometric_checks_passed=true` 不等于工程可发布；`engineering_release_ready` 明确为 false。

## 尚未解决，按优先级排序

### P0：冻结接口前必须解决

1. **真实传感器封装与光学堆叠。** 必须取得封装外形、支承/夹持禁区、有效面高度、公差、盖玻璃/滤镜堆叠与热接口。现有 40×28 mm 只是占位。如采用候选 IMX410，Sony 公开 flyer 的 41.071×30.815 mm 是 chip size，已经大于当前占位，而且不是完整封装图，不能直接画焊盘或定载架。
2. **实际镜头接口和镜头后组。** 需要供应商卡口/锁止/接触结构、真实后组侵入包络、通光锥、选定镜头清单及法兰调整/重复定位要求。当前 E/EF 环不可宣称兼容真实镜头。
3. **热路径与功耗。** 传感器占位件到铜色热方案占位体仍相距 **19 mm**，没有实现导热桥。必须根据传感器和主控功耗选择导热路径、温升目标和验证工况；铜色实体不代表已经散热。
4. **真实电子堆叠。** 当前只有低速台架控制板的板体和少量元件包络。需完整 populated STEP、主控/电源/高速传感器链路布局、连接器配对和线束弯曲/插拔区。
5. **完整固定与结构闭合。** 传感器夹持、桥架和横梁的螺钉/螺纹或螺母、定位销、防转、预紧、调整后锁定未定。机壳/握柄到金属骨架的连接、后盖和显示的保持结构也未完成，不能声称扭矩载荷已经传到底座。

### P1：打样前的工程验证

- 法兰距/平行度/倾角公差链、温度漂移、受力变形与重新换模块后的重复性。
- 装拆工具可达性、真实紧固件/线缆/密封件完整路径，按钮行程、编码器和双行程快门结构。
- 电池与储存实际产品、保护电路、保持与防反插、电源和安规要求。
- 制造工艺、拔模或加工可达性、壁厚/圆角/螺纹/插装配合，跌落、振动、热、EMI 和密封测试。
- 原型握持、按键触达、镜头与指节间隙、重心、背带与三脚架接口。

### P2：在功能结构稳定后

纹理、饰件、屏幕 UI、配色、外观接缝优化。不可让这些工作替代 P0/P1。
