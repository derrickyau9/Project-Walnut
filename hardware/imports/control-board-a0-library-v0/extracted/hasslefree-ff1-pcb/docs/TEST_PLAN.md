# First-article bench test plan

Status: **procedure only, NOT executed**. Perform after an independent electrical/assembly review approves a prototype. No camera sensor or host board should be attached for initial testing. Use ESD-safe handling and low-voltage current-limited equipment.

1. **Pre-power inspection.** Compare all parts and polarities against the schematic/BOM. Confirm TLV803EA29DBZR is the non-R/non-V pinout, R values, capacitor values and LED cathode. Confirm switches are gold-contact B3F-1002-G. Inspect bridges and unsoldered pins. Verify J1 orientation by the square pin-1 pad, not the cable's colors.
2. **Unpowered continuity.** Verify J1 pins 2/6 and U1 pin 1 are ground. Verify J1 pin 1 reaches U1 pin 3. Verify U1 pin 2 reaches J1 pin 5. Verify each button shorts its RAW node to ground only when pressed. Check that V3V3 and GND are not shorted, allowing for capacitor charging in resistance mode. Do not use high-voltage insulation testers on populated electronics.
3. **Controlled power.** Start supply at 0 V, current limit 5 mA, connect negative to J1-2 and positive to J1-1. Raise to regulated 3.3 V, never 5 V or battery voltage. If current limit is reached or a part heats, switch off and inspect. Expected steady current is ordinarily well below 2 mA, but LED Vf/leakage must be measured. D1 should illuminate; low-current brightness is not guaranteed.
4. **Buttons.** With high-impedance oscilloscope probes, observe J1-3/4. Released steady level should approach V3V3; each corresponding pressed level should approach GND. Verify the other channel is unaffected. Record rising/falling response and bounce. Nominal RC values are 1.1 ms release and 0.1 ms press; parasitic/load effects may alter them. Record both pressed simultaneously as a separate state. Pass criteria must use the chosen host's actual VIH/VIL limits.
5. **Supervisor.** Observe J1-5 with the supply on channel 2. From 3.3 V, ramp down slowly through 2.93 V and record reset assertion. Ramp up and record the release delay from the rising threshold crossing; expected nominal 200 ms and specified A-option range 130–270 ms under TI conditions. Falling threshold specification corresponds to 2.8714–2.9886 V across temperature, not a room-temperature calibration promise. Do not demand guaranteed behavior below the POR floor. Check the exact datasheet hysteresis conditions before applying limits.
6. **Supply transients.** After basic operation passes, use controlled low-voltage droops to characterize reset behavior. Avoid overshoot/negative voltage or uncontrolled cable tests. This does not constitute surge or ESD qualification.
7. **Host connection gate.** Document the host part, bank voltage, exact pin mapping, Schmitt capability, VIH/VIL, leakage, absolute maximum ratings, reset semantics and power sequence. Confirm the 3.3 V source is the same host-controlled source and no connector pin drives an unpowered bank. If any item is unknown, stop and leave the host disconnected.
8. **Firmware.** Use host pins as inputs only; disable inappropriate internal pulls; sample after valid supply. Start with 20 ms stable-state debounce. Verify repeated/held/simultaneous presses and rapid power cycling. Application software must choose how to interpret both buttons; no firmware or sensor triggering is included here.
9. **Record.** Save board serial number, exact populated MPNs, equipment, temperature, supply current, waveforms, observed threshold/delay and failures. Only after tests and revisions may a separate production readiness decision be made.
