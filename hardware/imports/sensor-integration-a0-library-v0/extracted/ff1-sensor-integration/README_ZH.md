# FF-1 · 传感器与主处理硬件集成包

2026-11-05。此包继续推进控制板之后的成像链路，**不是已完成的 IMX410 传感器 PCB 或主板**。它把可核实的信息转化为接口文件、计算脚本与明确的设计放行条件，未伪造未知引脚。

## 已推进的决定

- 首个成像台架候选：IMX410 子板 → 8 路 SLVS-EC → ZCU102 的 HPC0 → 可支持 RAW14 的接收 IP → DDR 帧缓存。
- 量产小型化候选：核查具有足够 **PL GTH** 通道的 SoM；TE0807 系列值得进一步匹配具体 SKU/修订。**尚未最终选型或采购。**
- 7010/7020、KR260 原生两路相机口、仅有 PS GTR 的小型 SoM，不能仅凭产品名当作八路直接接收方案。
- 传感器完整数据包和 IP 条款仍是下一步关键阻塞。没有把 Sony 两页 flyer 当成完整数据手册。

## 吞吐结论

按公开的 6064×4040、14-bit、19.2 fps 模式计算，每帧紧凑 RAW 为 **42.87 MB**，有效像素载荷约 **823.15 MB/s**。若以 16-bit 容器存入 DDR，每帧约 **49.00 MB**，四帧缓存至少 **195.99 MB**；每帧一次写入加一次读取已约 **1.88 GB/s**，尚未包含协议、消隐、额外 ISP 处理或内存效率损失。

这些数值是读出/缓存预算，不意味着相机必须持续按 19.2 fps 写卡。单张拍摄可先缓存再慢速写入；连拍长度与平均拍摄间隔必须按实际介质速度约束。没有假定压缩率。
